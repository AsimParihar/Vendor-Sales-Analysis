# Vendor Sales Analysis

An end-to-end **Data Analytics project** focused on analyzing vendor sales, purchasing, inventory, pricing, and profitability to uncover actionable business insights.

### 🔍 Project Overview

This project uses **SQL, Python, ETL, Exploratory Data Analysis (EDA), and Power BI** to transform raw vendor and sales data into meaningful business insights. The analysis focuses on identifying high-performing vendors, sales and profit trends, inventory efficiency, pricing patterns, and opportunities for business optimization.

### 🛠️ Tech Stack

* **SQL** — Data extraction, transformation, joins, aggregations, CTEs and analytical queries
* **Python** — Pandas, NumPy, Matplotlib, Seaborn
* **ETL** — Data ingestion, cleaning, transformation and loading
* **EDA** — Statistical analysis, trend analysis, outlier detection and correlation analysis
* **Power BI** — Interactive dashboards, DAX measures, KPIs and business reporting

### 📊 Key Analysis

* Vendor-wise sales and purchase performance
* Revenue, profit and profit-margin analysis
* Top and underperforming vendors
* Product-level sales performance
* Inventory and stock efficiency
* Pricing and cost analysis
* Sales trends and business KPIs
* Identification of potential optimization opportunities

### 🚀 End-to-End Workflow

**Raw Data → ETL → SQL Database → Data Cleaning → EDA → Business Analysis → Power BI Dashboard → Insights**

### 🎯 Business Objective

The goal is to provide a data-driven view of vendor performance and help businesses make better decisions around **vendor management, inventory planning, pricing, product performance, and profitability**.

This project demonstrates an end-to-end analytics workflow from **raw data to production-ready business insights**.
